# content/projects：真实任务应用

用于把所学内容应用到一个真实问题，并保留修改前后的版本。

## 计划产出

- `真实任务候选评分.md`：旧文件名用于路径兼容，实际记录统一成长树 S1 场景选择与必要的替换理由。
- `真实任务说明_V0.1.md`：首次独立完成的任务说明。
- `真实任务说明_V0.2_闭卷重写.md`：不看 V0.1 重写，只修用户结果、AI 必要性和边界。
- `真实任务说明_V1.0.md`：获得反馈并修改后的可交付版本。

## 任务说明应包含

- 要解决的真实问题与目标用户。
- 输入、输出和成功标准。
- AI Native 方案及其适用边界。
- 工具、流程、风险和验证方法。
- V0.1 到 V1.0 的主要修改及原因。
