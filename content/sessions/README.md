# 学习过程笔记

`content/sessions/` 保存实际学习过程中形成的笔记，例如观看视频、阅读文档时记录的概念理解、个人感悟、疑问、证据边界和认知变化。

## 与其他目录的边界

- `sessions/` 回答“我怎样理解、哪里产生变化、还有什么问题”。
- `practice/S1/` 回答“当天计划要求提交什么、是否达到通过标准”，是唯一日练主提交件。
- `knowledge/` 保存经过提炼、核验、能够跨任务复用的稳定知识。
- `evidence/S1/` 保存正式考核及受控验证材料。

Session 可以比当天练习包含更丰富的知识内容，但不能替代练习、考核或任务状态。会话写得很完整，也不表示对应任务已经完成或能力已经形成。

`sessions/` 不承担任务提交或正式验收；所有当天必答内容和通过检查仍回到对应的 `practice/S1/` 主练习。

## 使用规则

1. Session 是可选笔记；有值得保留的理解、感悟或疑问时再创建，不要求每天机械生成。
2. 每份笔记应尽量记录学习日期、关联任务、实际来源和仍待核验的问题。
3. 不在 Session 中维护任务 checkbox、`task_state`、当前任务或能力等级。
4. 与主练习相关的结论回填到对应 `practice/S1/Dxx_*.md`；不以 Session 链接代替主提交内容。
5. 可迁移且经过验证的结论再提炼到 `knowledge/`，不要直接把整份过程笔记复制为知识资产。
6. 资料摘录、个人推断和已经验证的结论要明确区分，避免把学习感悟误写成事实。

推荐使用 `00-templates/02-learning/每日学习会话模板.md`，也可以保留自然笔记形式；模板只帮助组织内容，不建立第二套任务状态。
