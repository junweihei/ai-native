# AI Native 内容目录

`content/` 是 Learning OS 的唯一正式学习内容区。Markdown 是权威内容源，网站、Word 和其他展示形式都从这里派生。

## 目录职责

- `system/`：上位共识、执行规则、模板规范和资产盘点。
- `plans/AI_Native_系统学习与统一成长树实践路线_V3.0.md`：当前唯一 canonical 战略总纲。
- `plans/S1/`：当前 S1 的唯一阶段执行计划与极简入口。
- `knowledge/`：知识地图、结构草稿和节点学习成果。
- `cases/`：案例拆解。
- `practice/`：测试、练习、错因分析和复测。
- `projects/`：真实任务和项目成果。
- `evidence/`：闭卷、迁移、Eval、周复盘和月度验收。
- `sessions/`：每日学习过程、当前差距和下一次续接点。

## 内容规则

1. 新的正式学习内容只能进入上述目录。
2. `plans/` 决定任务顺序，`knowledge/` 负责知识导航，两者不互相替代。
3. 成果放在对应类别目录；每日过程放在 `sessions/`，不能只保存在聊天记录中。
4. 文件状态使用 `config/learning-content.json` 定义的统一枚举。
5. 创建交付件时使用 `00-templates/template-registry.yaml`，不要自行发明平行模板。
6. Word 发布版进入 `exports/word/`，历史资料进入 `archive/`。
7. 网站只读取生成索引，不直接维护第二套学习状态。
8. `knowledge/AI_Native_知识节点注册表_V1.0.md` 只定义知识结构、四问、关系和证明规则；目标等级不等于当前能力，当前能力必须由独立证据支持。
