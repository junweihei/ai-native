# AI Native 学习内容

`content/` 是 Learning OS 的正式学习内容区。Markdown 是权威内容源，网站、Word 和其他展示形式都从这里派生。

## 学习者唯一入口

日常学习只从 [`plans/S1/开始这里.md`](plans/S1/开始这里.md) 进入。

正常执行路径只有三步：

```text
开始这里
→ `practice/S1/` 中保留当前任务的首次版本
→ 学习当前任务指定的资源；需要时在 `sessions/` 记录学习笔记
→ 回到 `practice/S1/` 完成唯一主成果和自检
```

战略总纲、运行规则、模板规范和资产盘点用于规划或维护，不是每日必读材料。

## 学习结构

```text
长期目标
→ 阶段目标与阶段任务
→ 每日唯一成果
→ 阶段性考核与延迟复测
→ 针对稳定弱点的补充练习
→ 可复用结论沉淀
```

- 每日任务检查“今天的结果是否完成”，不要求每天对每个知识点进行正式考核。
- 正式考核只放在 P1、P2、P3 和 S1 Final；首测、复测和独立讲解是日练中的形成性证据。
- 偶发小错记录即可；重复出现的同类弱点，或涉及核心边界和高风险判断的错误，才触发补充练习。
- 只有可迁移的判断规则、稳定错因、关键边界和经过验证的方法进入长期知识资产。

## 目录职责

- `plans/`：战略路线、阶段任务顺序、门禁和学习资源索引。
- `tasks/`：从阶段计划读取任务状态的查询看板，不保存第二套状态。
- `practice/S1/`：D01–D20 每天一份练习、总结和完成检查，是日常学习成果的唯一活动目录。
- `sessions/`：可选的学习过程笔记，记录观看视频、阅读文档时形成的理解、感悟、疑问和认知变化；不承担任务提交或正式验收。
- `evidence/S1/`：P1、P2、P3、Final 四份正式考核，以及按条件开放的受控参考答案。
- `knowledge/`：从练习、会话和证据中提炼出的、可跨任务复用且经过验证的稳定知识资产，不保存未经筛选的学习过程笔记。
- `system/`：运行原则、执行协议、模板和历史盘点，主要供维护使用。

## 单一权威关系

- 战略与阶段关系：`plans/AI_Native_系统学习与统一成长树实践路线_V3.0.md`
- 当前阶段任务、checkbox 和任务状态：`plans/S1/S1_整体认知与机制判断_执行计划_V1.0.md`
- 当前任务学习资源：`plans/S1/S1_整体认知与机制判断_学习资源_V1.0.md`
- 当前学习入口：`plans/S1/开始这里.md`
- 实际能力：只能由日练成果、正式考核、迁移、延迟复测或真实应用证据支持。

其他文件不得复制维护任务状态。开始页、看板和网站只读取或投影权威状态。

## 内容规则

1. 新的正式学习内容只进入上述目录。
2. 每个任务只有一个主成果；过程记录不能替代成果，长总结不能替代能力证据。
3. 每天只有一份日练主提交件；可以在 `sessions/` 另记学习笔记，但它是可选过程记录，不是第二份提交件、第二套任务状态或正式能力证据。
4. 未开始的模板不代表任务已经开始，也不进入日常学习入口。
5. 创建交付件时使用 `00-templates/template-registry.yaml`，不建立平行模板。
6. Word 发布版进入 `exports/word/`，历史资料和一次性盘点进入 `archive/`。
7. 网站只读取生成索引，不维护第二套学习状态。
8. Session 中值得长期复用的内容必须经过提炼和核验后再进入 `knowledge/`；原始感悟、资料摘录和未验证推断保留在 Session。
