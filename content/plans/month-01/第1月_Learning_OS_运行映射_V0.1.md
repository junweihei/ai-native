# AI Native 第1月 Learning OS 运行映射 V0.1

> 本文件把第一个月已有的目标、手册、资源、D1—D20 任务、知识节点、成果、证据、依赖和状态连接成一套可执行运行模型。
>
> 它是“关系与状态层”，不是第二套学习计划，不替代第一个月 V2.1 执行手册，也不复制每日资源正文。

---

## 一、这份映射解决什么问题

本映射集中回答七个运行问题：

1. 今天的任务承接哪个月度目标和周阶段？
2. 今天需要哪些知识节点和官方资源？
3. 今天应该执行什么动作，而不是继续泛读什么？
4. 今天必须把成果保存在哪里？
5. 什么证据出现后，任务才算完成？
6. 当前任务依赖什么，完成后解锁什么？
7. 练习、测试和复盘产生的反馈怎样改变后续计划？

```text
六个月总纲
→ 第1月里程碑
→ 四个周阶段
→ D1—D20 每日任务
→ 知识节点 + 指定资源 + 学习动作
→ Markdown 成果 + 能力证据
→ 日/周/月门禁
→ 下一任务或补强任务
```

## 三、第一个月在六个月路线中的位置

### 1. 月度里程碑

**M01：建立可以离开资料使用的 AI Native 判断框架。**

能够从业务结果出发，理解模型、知识、工具、Workflow、Agent、评测和治理之间的关系；判断什么时候不使用 Agent；把一个真实问题写成可验证的一页任务说明，并用闭卷与迁移证据决定第 2 月练什么。

### 2. 本月能力目标

| 能力 ID | 月末能力 | 目标等级 | 主要形成任务 | 主要证明任务 |
|---|---|---:|---|---|
| M01-C01 | 画出整体结构，解释六层、三条流及关键关系 | L2 | D1、D4、D5 | D18 |
| M01-C02 | 在规则、固定 Workflow、单次模型、Agent 之间做适用性判断 | L2 | D2、D3、D9、D11 | D12、D14、D19 |
| M01-C03 | 从优秀与普通案例中拆出业务、知识、工具、流程、评测与治理 | L2 | D6—D9 | D10、D18 |
| M01-C04 | 从真实问题形成有边界、可验收的一页任务说明 | L3 | D15—D17 | D17、D20 |
| M01-C05 | 用测试、闭卷、迁移和复盘判断能力并选择下一弱点 | L2 | D12—D14 | D18—D20 |

能力等级沿用六个月总纲：L0 未进入、L1 能解释、L2 能判断、L3 能实践、L4 能验证并改进。

### 3. 本月明确不做

- 不开发完整产品。
- 不提前固定框架、云平台、数据库或模型供应商。
- 不把术语数量、文章数量或总结长度当作成绩。
- 不因为产品名称含有 Agent，就默认自己的问题需要 Agent。
- 不提前查看 D12、D14、D18 和 D19 的受控材料，破坏闭卷证据。

## 五、状态模型与完成规则

| 状态 | 含义 | 进入条件 | 下一步 |
|---|---|---|---|
| 未开始 | 尚未进入正式执行 | 前置任务未完成或尚未排到 | 等待依赖 |
| 学习中 | 已阅读、讨论或总结，但主要成果尚未通过 | 已经开始输入或行动 | 完成指定成果并自检 |
| 待验收 | 主要成果已形成，尚未按标准自检 | 成果文件非空且结构完整 | 只修一个问题 |
| 已完成 | 主要成果存在并满足当天标准 | 成果、理由和自检齐全 | 进入下一任务 |
| 已验证 | 已被周关卡、闭卷、复测、迁移或月末门禁再次证明 | 后续独立证据支持 | 保持历史版本 |
| 阻塞 | 缺资源、数据、权限，或连续两次未通过同类任务 | 已记录具体卡点 | 降级资源或缩小练习 |

```text
阅读或讨论完成
≠ 指定成果完成
≠ 每日任务通过
≠ 周关卡验证
≠ 月度能力形成
```

任务标记为“已完成”至少需要：

1. 指定主要成果文件已经填写。
2. 成果是学习者自己的判断，不是直接复制 AI 或参考答案。
3. 手册规定的当天通过条件已经自检。
4. 若使用 AI 反馈，只修改一个明确问题，并保留首次版本或差异。

`content/sessions/AI_Native_D*.md` 是学习会话总结和支持成果；手册指定独立成果文件时，每日总结不能替代该文件。

### D2 证据补链

1. 关闭 D2 总结和 R2，在指定文件列出 8 个自己的真实任务。

## 十、每日运行与状态更新协议

### 开始前

1. 在本映射确认当前任务、依赖和周门禁。
2. 打开每日资源文件的当天部分。
3. 打开主要成果文件，先写“结束时必须看见什么”。
4. 若任务要求闭卷，关闭总结、答案和外部资料。

### 执行中

```text
定位结果
→ 闭卷首做
→ 只读指定资源
→ 写入指定成果
→ 按标准自检
→ 只修一个问题
```

单次超过 90 分钟仍未完成时，保存当前版本并记录具体卡点；状态保持“学习中”或改为“阻塞”，不无限扩展阅读。

### 结束后

记录六项：任务 ID、成果路径、通过/未通过标准、一个未解决问题、能力状态变化证据、下一次续接点。

### 状态更新

- 成果未达标：保持“学习中”，记录一个差距。
- 达到当天标准：更新为“已完成”，解锁下一任务。
- 周关卡通过：相关能力进入阶段“已验证”。
- 门禁未通过：新增一个小于 30 分钟的补强任务，不扩大资料范围。
- 权限、数据或风险不成立：停止推进，不用假设结论冒充验证。
