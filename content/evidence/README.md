# content/evidence：正式考核与受控证据

`evidence/` 只保存需要独立性、评分口径或开放条件的正式证据，不再保存普通日练或每日总结。

## S1 正式考核

- [`P1_整体认知考核.md`](S1/P1_整体认知考核.md)：验证整体结构与机制边界。
- [`P2_案例拆解考核.md`](S1/P2_案例拆解考核.md)：用未见案例验证迁移。
- [`P3_机制判断与真实任务考核.md`](S1/P3_机制判断与真实任务考核.md)：验证机制判断与真实任务可行性。
- [`FINAL_S1阶段考核.md`](S1/FINAL_S1阶段考核.md)：汇总六类证据并执行延迟未见场景复测。

## 受控材料

S1 首测和复测参考答案也存放在 `S1/`，但它们是辅助材料，不是提交件，不建立学习任务状态。开放条件以 `config/controlled-materials.json` 为准。

正式考核必须保留首次作答、题目快照、评分标准和必要的完整性证据；评分后修订不能覆盖原始证据。
