# content/practice：每日练习主文档

`practice/` 保存日常学习的唯一主提交件。S1 的正式执行目录是 [`S1/`](S1/)：D01–D20 每天恰好一份文件。

## S1 规则

- 每份文档都包含：今日目标、指定资源、今日练习、练习总结、完成检查。
- 首次独立作答、资源对照、修订和总结写在同一文件中，不拆成开卷版、闭卷版或会话记录。
- 每日 checkbox 只是成果自检；权威任务状态只在 S1 执行计划维护。
- 受控参考答案不属于每日提交件，存放在 `content/evidence/S1/` 并按条件开放。
- 正式阶段考核不放在本目录，统一进入 `content/evidence/S1/`。

## 学习闭环

```text
明确今日结果
→ 保留首次独立版本
→ 只读指定资源
→ 在同一文档聚焦修正
→ 完成总结与检查
```
