## 1. 冻结原则

1. “深色系统工作台 + 浅色学习纸张”是固定方向：导航、关系和状态在深色表面；长文本、成果编辑、四问和复盘输入在浅色纸张。
2. 每个画面仅一个青色高强调主行动；其余操作使用边框或文字样式。
3. 运行状态使用“任务：学习中 / 已完成 / 阻塞”等带对象的圆角标签；能力等级使用独立的六边形轮廓标记“能力：L0—L4 / 待证据判断”。两者不得合并、互相推导或共用标题。
4. 绿色只表示有证据支持或写入成功；琥珀表示待处理、过期或门禁；红色只表示错误或高风险。所有颜色同时配文字、图形或位置。
5. 受控材料在开放前只显示材料类别和开放条件，不显示文件名、正文、摘要、答案字母或可推断结论。
6. 所有正式提交旁显示目标仓库相对路径、数据来源、索引生成时间和权威版本；写回失败时保持输入、状态不前移。
7. 冻结 V3 只提供视觉气质参考；本文、上游基线和内容契约是行为与数据权威。

## 2. 尺寸与布局规格

| 项目 | 桌面 ≥1024 | 中宽 480—1023 | 窄屏 320—479 |
|---|---:|---:|---:|
| 应用导航 | 左栏 88；标识 32；入口触控区 64×56 | 左栏 72；辅助栏落到正文后 | 底栏 64；五入口各 ≥44 高，短标签“今日/路线/知识/档案/复盘” |
| 顶部栏 | 高 72；左右内边距 32 | 高 64；内边距 24 | 高 56；内边距 16；返回、标题、状态同一阅读序列 |
| 主内容 | 最大内容宽 1280；页边距 32；区间 24/32 | 页边距 24；双栏转单栏 | 页边距 16；单栏；区间 16/24；底部留 80 |
| 任务工作台 | 主栏 minmax(0,2fr)，辅栏 360 | 辅栏移至主栏后 | 步骤摘要“步骤 n/8 + 当前名”；完整步骤按需展开 |
| 阅读纸张 | 最大正文行宽 72 个中文字符；内边距 32 | 内边距 24 | 内边距 16；输入字号 16 |
| 地图/表格 | 允许局部横向浏览，主行动不随画布滚动 | 局部横向浏览有可见提示 | 转卡片；确需横滚只限局部容器，不产生双向页面滚动 |

页面纵向自然滚动，不使用嵌套长滚动。首屏顺序固定为：位置 / 风险 → 主任务或主问题 → 唯一主行动 → 完成条件 / 当前步骤 → 辅助关系。200% 缩放按中宽或窄屏规则重排，不隐藏功能。

## 3. 设计令牌

### 3.1 色彩与表面

| 令牌 | 值 | 约束 |
|---|---:|---|
| `surface.canvas` | `#07101F` | 应用背景 |
| `surface.raised` | `#0D1A2F` | 导航、结构面板 |
| `surface.subtle` | `#111F36` | 次级分组、悬停 |
| `surface.paper` | `#F5F7FB` | 长文本、成果和复盘输入 |
| `border.default` | `#223553` | 1px 结构边界 |
| `text.primary.dark` / `secondary.dark` | `#E8F1FF` / `#8EA3C4` | 深色表面文本 |
| `text.primary.paper` | `#172033` | 浅色纸张正文 |
| `action.primary` / `secondary` | `#4EE7FF` / `#6D8CFF` | 当前焦点 / 次级结构 |
| `status.verified` / `warning` / `danger` | `#5DE3AD` / `#FFC96B` / `#FF7C91` | 有证据 / 待处理 / 错误 |

主按钮：高 44、左右内边距 20、圆角 8、青色底与深色文字；焦点环 3px 青色并留 2px 间隔。普通卡片无阴影，1px 边界；仅对话框使用 0 16 48 / 36% 阴影。

### 3.2 排版、间距与形状

- Display 36/1.2，H1 30/1.25，H2 23/1.35，H3 18/1.45，Body 16/1.65，Small 14/1.5，Meta 12/1.4；仅 400、500 两档字重。
- 基础间距 4；序列 4、8、12、16、24、32、48。控件圆角 8，卡片 12，重点纸张 18。
- 运行状态为圆角矩形并带“任务 / 成果 / 会话”对象前缀；能力等级为六边形轮廓并带“能力”前缀。成功、错误、过期均不可覆盖对象原状态。
- 动效：控件反馈 160ms，视图重排 220ms；只对位置、展开和状态变化使用。`prefers-reduced-motion` 下取消位移与过渡，结果文案保持。

## 5. P0 闭环交互

### UF-01 今日任务

今日“继续当前任务” → 工作台恢复续接点 → 完成当前协议步骤 → 成果差异预览 → “提交成果” → 自检 → 会话收尾 → “进入日复盘” → “保存日复盘并生成续接点” → 今日显示新续接点。每次转场携带任务 ID、来源、步骤、草稿状态、权威版本和数据新鲜度；提交失败停留原屏。

### UF-02 受控材料

受控占位 → “开始闭卷首做” → 独立纸张 → “保存首次版本” → 首版确认 → 开放条件校验 → “打开指定参考材料” → 首版/参考分区对照 → 单点修订 → 自检。开放前普通导航、档案、知识关联与搜索只展示“首测参考材料；保存首次版本后开放”。

### UF-03 证据缺口

复盘显示一个优先差距 → “处理当前优先差距” → 允许的补强任务 → 提交成果/证据 → 返回复盘 → “确认本次调整” → 今日反馈计划。没有计划关系时只记录“关系缺失”，不生成权威任务。

## 6. 页面与组件状态

九个页面状态均可在原型中切换；“未保存保护”作为高于九态的阻断层演示。

| 状态 | 页面级文案与唯一主行动 | 关键约束 |
|---|---|---|
| 默认 | 显示真实对象和当前主行动 | 数据源、时间、状态对象始终可见 |
| 加载 | “正在读取任务关系…”；“返回来源” | 骨架不显示 0、空档案或假状态 |
| 空 | “此范围没有可执行任务”；“查看路线图” | 说明对象范围和原因，不自动创建 |
| 部分数据 | “周计划关系缺失；当前成果仍可阅读”；“查看缺失关系” | 不补造父级、能力或证据 |
| 错误 | “写回失败；草稿已保留，权威文件未改变”；“重试提交” | 输入可复制，任务仍为学习中 |
| 成功 | “已写入 `content/knowledge/任务适用性判断_D2.md`；任务仍待验收”；“进入自检” | 成功不等于验证 |
| 只读 | “当前为只读；权威文件未改变”；“复制草稿” | 浏览与复制可用，正式提交禁用 |
| 过期 | “索引生成于 09:10；提交和受控材料开放已暂停”；“刷新数据” | 原对象状态仍显示，不被“过期”覆盖 |
| 阻塞 | “缺指定输入；已有草稿已保留”；“记录阻塞” | 显示解除条件、降级路径，不计完成 |
| 未保存保护 | “离开将影响未保存修改”；“保存草稿并离开” | 次要“留在页面”；危险“放弃修改” |

组件适用态：按钮覆盖默认/焦点/按下/禁用/加载；任务卡、完成标准、证据卡、输入区、状态标签、持久反馈覆盖上述九态；对话框覆盖未保存、差异确认、冲突和不可逆放弃。不适用说明：非编辑页不产生未保存态；显示型状态标签无按下态；加载骨架无交互态。

## 7. 可实现的交互与文案

- 键盘顺序：跳至主内容 → 返回来源 → 页面 H1 → 环境/来源状态 → 唯一主行动 → 当前步骤或首字段 → 次要行动 → 辅助关系 → 全局导航。对话框打开后焦点到标题，限制在对话框内；关闭后回到触发控件。
- 保存中按钮保留原宽度，文案“正在保存首次版本…”，防止重复触发；结果以按钮附近和页面持久反馈两处表达。
- 字段使用持久标签：“闭卷首次判断”“一个未解决问题”“下一续接点”；错误摘要链接到对应字段。
- 数据来源格式：“来源：生成索引 · 权威：Markdown · 生成 2026-08-29 09:10”。路径使用仓库相对路径并允许复制。
- 写回错误固定文案：“提交失败；草稿已保留，`content/...` 未改变。可重试提交或复制草稿。”
- 只读固定文案：“当前为只读；你可以查看或复制内容，正式状态不会改变。”
- 阻塞固定文案：“任务因缺少指定输入而阻塞。已有成果已保留；补齐输入后可继续，或记录安全降级方案。”
- 受控材料固定文案：“首测参考材料尚未开放。保存闭卷首次版本后可查看；当前不提供正文、摘要或文件标题。”

## 10. 门禁结论

**结论：带明确修订项通过，可以进入数据契约设计。** DG-08、UI-01—10、AX-01—06 在设计层均有明确落点；HF-R01/02 是生产实现后的验证项，不影响数据契约启动。数据契约必须优先冻结 DC-D01—05，并把受控材料、草稿恢复、写回结果、权威版本和来源时间列为 P0 字段。
