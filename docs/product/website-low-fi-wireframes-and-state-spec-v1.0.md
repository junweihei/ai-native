## 1. 线框约定

### 1.1 标记

| 标记 | 含义 |
|---|---|
| `[P0]` | 发布阻断信息或操作，窄屏不得隐藏 |
| `[P1]` | 支撑计划和知识关系，可折叠但必须可发现 |
| `[P2]` | 历史查找或效率增强，可放到后部 |
| `[主]` | 页面当前唯一高强调行动 |
| `[次]` | 不改变当前主任务方向的辅助行动 |
| `[状态]` | 数据、保存、对象状态或能力等级反馈 |
| `→` | 页面或状态转移 |
| `↩` | 返回进入上下文并恢复筛选、选择和滚动位置 |

### 1.2 线框原则

1. 线框只表达信息结构、顺序、状态和交互权重，不表达最终颜色、字体、图标或像素细节。
2. 每页一个 H1、一个当前主问题和一个高强调主行动。
3. “今日→任务工作台→成果/证据→日复盘→续接点”先于所有 P1/P2 页面。
4. 桌面辅助栏进入窄屏主列后，按 P0→P1→P2 排序，不能直接丢失。
5. 任务、会话、成果、证据状态始终带对象名称；L0—L4 单独放在“能力等级”区。
6. 受控内容在开放前只显示规则和条件，不显示答案正文、答案摘要或可推断结论。
7. 部分数据和错误不触发猜测；保留可用信息并明确缺口与恢复动作。

### 2.3 全局键盘焦点顺序

1. 跳到主内容。
2. 五个一级入口，当前入口可识别。
3. 上下文返回（仅任务工作台、知识节点详情）。
4. 页面 H1 与数据状态详情入口。
5. 非正常状态中的恢复动作。
6. 页面唯一主行动。
7. 主内容内次要行动，按视觉顺序。
8. 辅助区行动。
9. 页面末尾恢复/返回动作。

弹出对话框时，焦点进入标题后的第一个安全操作；关闭后返回触发控件。

## 5. 组件状态规格

### 5.1 通用状态规则

| 状态 | 必须表达 | 允许 | 禁止 |
|---|---|---|---|
| 加载 | 正在读取的对象和保留骨架 | 取消、返回 | 先显示 0/空结果 |
| 空 | 为什么为空、对象范围、一个合法下一动作 | 查看路线/清除筛选/返回任务 | 自动创建或猜测内容 |
| 部分数据 | 缺少字段/关系、影响范围、可用内容 | 浏览可用内容、查看问题 | 补造父级/状态/证据 |
| 错误 | 失败动作、权威文件是否改变、草稿是否安全、恢复动作 | 重试、复制、返回 | 只显示“出错了” |
| 成功 | 写到哪里、哪个对象变化、什么未变化 | 继续下一协议步骤 | 把提交成功等同验证成功 |
| 禁用 | 禁用原因和满足条件 | 查看原因、完成前置 | 无说明灰掉 |
| 只读 | 原因、权威未改变、可做什么 | 浏览、草稿、复制 | 正式提交/改状态 |
| 过期 | 生成时间、可能影响、刷新入口 | 阅读、临时草稿 | 提交、开放受控材料 |
| 阻塞 | 具体卡点、已有成果、解除条件、降级路径 | 记录、保存、复盘 | 计入完成/自动跳过 |

### 5.2 按钮

| 状态 | 主按钮 | 次要按钮 |
|---|---|---|
| 加载 | 保留原文案和宽度，显示处理中，防重复触发 | 无关动作可用；冲突动作禁用并说明 |
| 空 | 改为合法恢复动作，如“查看路线图”“清除筛选” | 查看原因/返回 |
| 部分数据 | 只有安全且不依赖缺失关系的主行动可用 | “查看缺失关系”常驻 |
| 错误 | 改为“重试读取/重试提交” | 复制内容、返回来源 |
| 成功 | 短暂显示明确结果，随后切换下一协议动作 | 查看写入位置/证据 |
| 禁用 | 文案保持具体，旁边或下方写原因 | 提供完成条件入口 |
| 只读 | 正式提交禁用；页面主行动可转为“复制草稿” | 浏览/返回可用 |
| 过期 | 主行动改为“刷新数据”；正式提交禁用 | 保存临时草稿可用 |
| 阻塞 | 主行动改为“记录阻塞”或“执行安全降级动作” | 查看解除条件 |

### 5.3 任务卡

| 状态 | 内容与行为 |
|---|---|
| 加载 | 保留任务卡结构，不显示假任务名或假状态 |
| 空 | 说明无当前任务及原因，主行动去路线图 |
| 部分数据 | 显示已知任务 ID/名称，缺失目标/门禁单独标注，不可正式开始 |
| 错误 | 保留上次可见任务标题（若可靠）并标为不可确认；提供重试 |
| 成功 | 只在成果和规则通过后显示任务“已完成”；能力等级不随卡变化 |
| 禁用 | 显示具体依赖或门禁，不使用笼统“不可用” |
| 只读 | 可进入只读任务工作台，不能提交或改状态 |
| 过期 | 显示任务和时间戳，开始/继续正式会话前要求刷新 |
| 阻塞 | 显示卡点、已有成果和解除条件；不进入完成统计 |

### 5.4 完成标准

| 状态 | 内容与行为 |
|---|---|
| 加载 | 显示标准占位，不显示 0/全部未完成 |
| 空 | 属于数据缺失，不允许用“无标准”完成任务 |
| 部分数据 | 每项标注来源/缺失；整体不能通过 |
| 错误 | 保留用户已有自检输入，说明标准读取失败 |
| 成功 | 每项显示标准、证据、判断和来源；整体结论可追溯 |
| 禁用 | 未到自检步骤时可查看但不可提交结论 |
| 只读 | 可查看标准和历史结论，不可改写 |
| 过期 | 可自查临时结果，正式提交结论暂停 |
| 阻塞 | 明确哪项标准被卡住及解除条件 |

### 5.5 证据卡

| 状态 | 内容与行为 |
|---|---|
| 加载 | 保留证据对象区域，不把未知当“无证据” |
| 空 | 明确“尚无可复查证据”和需要补什么 |
| 部分数据 | 显示已有路径/结果，缺标准或证明对象时标记不可用于升级能力 |
| 错误 | 显示关联读取失败，不降低或提升能力等级 |
| 成功 | 显示证明对象、标准、结果、路径、独立范围和更新时间 |
| 禁用 | 未形成成果时“关联证据”禁用并显示前置条件 |
| 只读 | 可查看和复制权威路径，不可修改判断 |
| 过期 | 显示历史证据但暂停新的能力判断 |
| 阻塞 | 显示缺数据/权限/风险与可执行的补强动作 |

### 5.6 输入区

| 状态 | 内容与行为 |
|---|---|
| 加载 | 已恢复的本地草稿保持可读；权威内容加载区单独占位 |
| 空 | 保持持久标签、任务提示和目标路径，不用 placeholder 代替标签 |
| 部分数据 | 若缺少任务标准，允许临时草稿但禁止正式提交 |
| 错误 | 输入不清空；显示最后保存时间、复制和重试 |
| 成功 | 显示保存/写入位置和时间；输入是否清空由下一步骤决定 |
| 禁用 | 只在受控首版锁定、提交中或不允许编辑时使用，并说明原因 |
| 只读 | 正文可选择/复制；提供独立临时草稿区时明确不写回 |
| 过期 | 允许临时草稿；提交前必须刷新并重新预览差异 |
| 阻塞 | 保留已有输入；附卡点记录和安全降级入口 |

### 5.7 状态标签

| 状态 | 规则 |
|---|---|
| 加载 | 使用“状态读取中”，不用无色空标签 |
| 空 | 使用“状态缺失”，不默认为未开始 |
| 部分数据 | 标签包含对象，如“成果：学习中；任务：待确认” |
| 错误 | 使用“状态不可确认”，保留最后可靠时间 |
| 成功 | `completed` 显示“任务：已完成”；`verified` 显示“能力/任务：已验证”，不合并 |
| 禁用 | 标签不是操作控件，不呈现可点击错觉 |
| 只读 | 增加“只读”环境标签，不改变对象本身状态 |
| 过期 | 增加“数据过期”环境标签，不覆盖对象状态 |
| 阻塞 | 明确“任务：阻塞”，同时显示原因入口 |

### 5.8 反馈

| 状态 | 规格 |
|---|---|
| 加载 | 当前动作附近显示，不用全屏遮挡可继续阅读的信息 |
| 空 | 页面内持久呈现原因和合法动作 |
| 部分数据 | 页面顶部持久提示，相关区块内重复具体缺口 |
| 错误 | 页面内保留到恢复完成；包含影响、草稿、权威文件和下一动作 |
| 成功 | 明确“写到哪里/状态是否改变”；短反馈后在页面保留可追溯结果 |
| 禁用 | 原因靠近控件，可被键盘和辅助技术读取 |
| 只读 | 持久状态条，不只用一次性提示 |
| 过期 | 持久显示生成时间和刷新入口 |
| 阻塞 | 任务区内持久显示解除条件，不使用惩罚性文案 |

### 5.9 对话框

| 状态/用途 | 规格 |
|---|---|
| 未保存离开 | 标题“离开将影响未保存修改”；主行动“保存草稿并离开”；另有“留在页面”“放弃修改” |
| 提交差异确认 | 显示目标路径、权威版本和差异；主行动“提交成果” |
| 冲突 | 不允许覆盖；提供“重新加载并保留草稿”“复制草稿” |
| 破坏性放弃 | 说明将丢失的具体范围；主行动使用具体动词 |
| 加载 | 防重复提交，保留标题和结果范围 |
| 错误 | 对话框内显示失败，但恢复信息需要同时留在页面 |
| 只读/过期 | 不打开虚假提交确认；直接解释为何不能提交 |
| 阻塞 | 一般不用对话框；阻塞是可持续页面状态，除非记录动作需要确认不可逆后果 |

## 6. 状态组合优先级

多个状态同时出现时按以下顺序处理：

```text
未保存内容保护
> 提交冲突/错误
> 受控材料安全
> 全局只读或过期
> 任务阻塞
> 部分数据
> 对象正常状态
```

示例：任务处于 `blocked`，同时索引过期且输入未保存。页面首先保护未保存内容；保留任务阻塞信息；正式提交和受控材料开放因过期而禁用。不能只显示一个“阻塞”标签覆盖其他风险。
