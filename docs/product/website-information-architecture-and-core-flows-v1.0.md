## 1. 文档用途

本文件是低保真线框的直接输入，规定：

- 五个一级入口和两个上下文页面的职责与关系。
- 每个页面回答的问题、进入条件、信息顺序、唯一主行动和退出路径。
- UF-01、UF-02、UF-03 的逐屏状态与转场。
- 空、部分数据、过期、错误、只读、阻塞和未保存内容的恢复路径。
- 桌面、中宽和窄屏的信息排序。
- AC-P0-01—12 在具体页面和流程中的落点。

本文件只定义产品行为和信息结构。数据字段的最终形状、读写实现、框架、数据库、服务和部署方式不属于本阶段。

## 2. 信息架构原则

1. **今日决定起点**：应用打开后默认进入“今日”，不恢复到上次浏览的知识节点。
2. **计划决定顺序**：路线图展示计划，知识地图只提供知识上下文。
3. **任务承载执行**：完整学习会话只在任务工作台内推进；节点详情不建立平行任务流。
4. **一个页面一个主问题**：每页同一时刻只有一个高强调主行动。
5. **证据决定状态**：成果、任务、会话、证据和能力等级分别显示，不按相同 `task_id` 粗暴合并。
6. **返回来源上下文**：上下文页返回进入它的页面、筛选和滚动位置，而不是一律回首页。
7. **异常也是主流程**：部分数据、过期、只读、阻塞和未保存状态必须有可继续或可恢复的路径。
8. **受控内容默认不可见**：开放条件未满足时，不在页面、搜索、摘要、关联卡或预览中出现正文。
9. **不猜测权威关系**：无法确定唯一当前任务或父级关系时显示数据问题，不使用最近浏览或本地偏好补造。
10. **窄屏不降级 P0**：320 CSS 像素等效宽度仍能完成“今日→任务→成果/证据→日复盘→续接”。

## 3. 全局架构

### 3.1 页面层级

```text
应用
├─ 今日（一级，默认）
│  └─ 任务工作台（上下文）
├─ 路线图（一级）
│  └─ 任务工作台（上下文）
├─ 知识地图（一级）
│  └─ 知识节点详情（上下文）
│     └─ 任务工作台（上下文，可从相关计划任务进入）
├─ 学习档案（一级）
│  ├─ 知识节点详情（上下文）
│  └─ 任务工作台（上下文，仅查看关联任务时）
└─ 复盘（一级）
   ├─ 任务工作台（上下文，处理允许的补强任务）
   └─ 知识节点详情（上下文，查看证据缺口）
```

### 3.2 五个一级入口

| 顺序 | 入口 | 固定用户问题 | 默认主行动 |
|---:|---|---|---|
| 1 | 今日 | 我现在做什么，做到什么才算完成？ | 开始 / 继续当前任务 |
| 2 | 路线图 | 今天为什么做，之前和之后是什么？ | 回到当前任务 |
| 3 | 知识地图 | 当前任务涉及什么知识，它与什么相关？ | 查看当前任务关联节点 |
| 4 | 学习档案 | 我已经形成过什么可追溯成果和证据？ | 打开所选权威成果 |
| 5 | 复盘 | 进展真实吗，下一步应调整什么？ | 处理当前优先差距 / 完成当前复盘 |

全局导航不包含“任务工作台”和“知识节点详情”。上下文页面打开时，五入口仍可访问，但离开前必须处理未保存内容。

### 3.3 全局框架信息

所有页面共享以下框架：

1. 产品标识与五个一级入口。
2. 当前页面 H1 和一句页面目的。
3. 数据来源状态：权威来源、最近生成/刷新时间、正常/过期/部分/只读/错误。
4. 页面级主行动区域。
5. 必要的持久反馈区；需要恢复的信息不能只用短暂提示。

### 3.4 当前任务选择行为

信息架构采用以下行为，具体字段在数据契约阶段确定：

```text
存在显式 current_task 且依赖/门禁允许
→ 使用该任务

没有显式 current_task，但只有一个符合计划、依赖和门禁的任务
→ 使用该任务，并标注“根据计划关系确定”

没有符合条件的任务
→ 今日空状态：说明原因，主行动转为“查看路线图”

存在多个同等候选或关系冲突
→ 今日数据问题：列出候选与缺失关系，不猜测，不提供正式开始按钮
```

最近浏览、知识节点顺序和本地界面偏好不能决定当前任务。

### 3.5 返回上下文模型

打开上下文页时保留：

- 来源页面。
- 来源页面的筛选、选中项和滚动位置。
- 打开原因，例如“继续当前任务”“查看节点证据”“处理复盘缺口”。
- 未提交输入状态。

返回规则：

- 正常返回：恢复来源页面状态。
- 完成任务后：先进入日复盘，不直接回来源。
- 日复盘完成后：回“今日”显示新续接点。
- 来源已失效：回到对应一级入口顶部，并说明上下文已变化。

## 4. 页面模型

### IA-01 今日

| 项目 | 定义 |
|---|---|
| 用户问题 | 我现在位于哪里、今天只做什么、为什么做、做到什么算完成、从哪里继续？ |
| 进入条件 | 应用默认启动；全局导航进入；日复盘完成后返回；上下文失效时安全回退 |
| 主要信息 | 数据状态；六个月/月/周/日位置；唯一当前任务；任务状态与预计时间；上层能力目标；选择原因；主要成果；完成规则；证据要求；依赖/门禁；上次会话时间、未解决问题和下一动作 |
| 唯一主行动 | 有可执行任务时：“开始当前任务”或“继续当前任务”；无任务时：“查看路线图”；关系冲突时不提供正式主行动，显示“查看数据问题” |
| 次要行动 | 查看上层路线、展开完成标准、查看相关节点、查看已有成果/证据、查看数据来源详情 |
| 退出去向 | 主行动进入任务工作台；计划位置进入路线图；节点进入知识节点详情；成果进入学习档案；全局导航进入其他一级入口 |
| 返回上下文 | 一级入口，无页面内返回；从日复盘返回时聚焦更新后的续接卡 |
| 覆盖 | PS-01；UF-01；FR-01、FR-02、FR-03、FR-06、FR-07；AC-P0-01、02、03、11 |

#### 今日信息区块顺序

1. **数据状态条**：只在正常以外持续显示；正常状态可压缩为更新时间。
2. **计划位置**：六个月目标 → 月度里程碑 → 周阶段 → 今日任务。
3. **当前任务主卡**：任务名称、为何现在做、预计时间、状态、唯一主行动。
4. **完成定义**：主要成果、最低完成规则、证据要求、门禁。
5. **续接卡**：上次结束时间、一个未解决问题、下一动作。
6. **辅助关系**：相关知识节点、已有成果/证据、风险。

#### 今日线框必须画出的状态

- 可开始、可继续、无当前任务、多个候选冲突、前置未满足、当前任务阻塞。
- 索引正常、部分、过期、加载失败、只读。
- 续接点存在、缺失、指向无效步骤。

### IA-02 路线图

| 项目 | 定义 |
|---|---|
| 用户问题 | 今天的任务如何服务周、月和六个月目标；下一任务为什么尚未解锁？ |
| 进入条件 | 全局导航；今日计划位置；任务工作台上层追溯；复盘查看调整影响 |
| 主要信息 | 六个月阶段；月度里程碑；周计划/阶段；每日/专项任务；当前路径；时间范围；状态；依赖；门禁；验收关系；计划调整记录 |
| 唯一主行动 | “回到当前任务”；没有当前任务时为“查看第一个可行动项”；存在冲突时不提供执行按钮 |
| 次要行动 | 展开/折叠层级、选择计划项查看详情、查看门禁证据、查看调整记录、返回今日 |
| 退出去向 | 当前任务进入任务工作台；计划项相关节点进入知识节点详情；复盘记录进入复盘；全局导航 |
| 返回上下文 | 一级入口；从任务/复盘进入时返回原来源并保留所选计划项 |
| 覆盖 | PS-02；FR-02、FR-09；AC-P0-02；AC-P1-01 |

#### 路线图信息区块顺序

1. 当前路径摘要和主行动。
2. 六个月阶段与当前月。
3. 当前周、门禁和任务序列。
4. 所选项详情：目标、依赖、验收、状态依据。
5. 过去/未来月份和调整历史。

路线图不得提供“按知识树开始学习”。被锁定任务可以查看详情，但不能显示为可立即执行。

### IA-03 知识地图

| 项目 | 定义 |
|---|---|
| 用户问题 | 当前任务涉及哪些知识，这个节点处于什么结构和证据状态？ |
| 进入条件 | 全局导航；今日/任务工作台查看相关节点；复盘查看能力缺口 |
| 主要信息 | 当前任务关联节点；六层功能架构；三条运行流；两类横向保障；知识层级和关系；目标能力等级；当前能力等级；成果/证据数量与缺口 |
| 唯一主行动 | 默认“查看当前任务关联节点”；已选节点时“查看节点详情” |
| 次要行动 | 展开/折叠、按层/流/保障定位、选择节点、查看相关任务/证据、返回今日 |
| 退出去向 | 进入知识节点详情；相关计划任务进入任务工作台；全局导航 |
| 返回上下文 | 一级入口；从任务/复盘进入时保留来源任务或缺口筛选 |
| 覆盖 | PS-04；FR-10、FR-11、FR-12；AC-P1-02、04、05 |

#### 知识地图信息区块顺序

1. 当前任务关联摘要和主行动。
2. 结构切换：层、流、保障三种关系视角。
3. 地图/树主区。
4. 所选节点摘要：四问概览、能力等级、运行状态、证据缺口。
5. 相关计划任务与成果证据。

“任务运行状态”和“知识能力等级”使用两个标题明确的区域；节点缺少结构化关系时显示部分数据，不自动归类。

### IA-04 学习档案

| 项目 | 定义 |
|---|---|
| 用户问题 | 某项成果、证据或历史版本在哪里，它证明什么？ |
| 进入条件 | 全局导航；今日已有成果；任务工作台成果/证据；节点详情；复盘证据引用 |
| 主要信息 | 成果视图/时间视图；搜索；月/周、任务、节点、类型、能力、证据状态筛选；标题；权威路径；更新时间；类型；对象状态；关联任务/节点/里程碑；版本/归档关系 |
| 唯一主行动 | 有选中项时“打开权威成果”；无选中项时“选择一项成果”；空结果时“清除筛选” |
| 次要行动 | 切换视图、筛选、排序、查看关联对象、复制权威路径、查看历史版本 |
| 退出去向 | 打开成果阅读视图；进入关联任务工作台或知识节点详情；全局导航 |
| 返回上下文 | 一级入口；从其他页面进入时保留预置筛选和返回来源 |
| 覆盖 | PS-06；FR-13、FR-14；AC-P2-01、02、03；DT-01 |

#### 学习档案信息区块顺序

1. 当前筛选语境和结果数量。
2. 搜索、筛选和成果/时间视图切换。
3. 结果列表。
4. 所选成果摘要、权威路径、关系和主行动。
5. 历史版本和归档信息。

受控材料未开放时可以显示“存在一项受控材料”和开放条件，但标题策略、摘要和正文必须遵循数据契约的默认拒绝规则；普通搜索不能命中未开放正文。

### IA-05 复盘

| 项目 | 定义 |
|---|---|
| 用户问题 | 实际进展说明了什么，当前最重要差距是什么，下一步如何调整？ |
| 进入条件 | 全局导航；任务工作台结束会话；今日查看风险；节点/路线图查看缺口或门禁 |
| 主要信息 | 日/周/月范围；计划与实际；任务结果；成果与证据；能力变化；一个最大差距；里程碑风险；调整动作；下一任务/续接点；判断依据 |
| 唯一主行动 | 日收尾模式：“保存日复盘并生成续接点”；日常查看：“处理当前优先差距”；周/月模式：“确认本期唯一调整” |
| 次要行动 | 切换日/周/月、查看证据、查看相关节点/路线、记录不调整及理由、返回今日 |
| 退出去向 | 保存日复盘后回今日；处理缺口进入任务工作台；查看证据进入档案；查看节点/计划进入对应页面 |
| 返回上下文 | 一级入口；从结束会话进入时，未完成日收尾前返回任务工作台并保留输入 |
| 覆盖 | PS-07；UF-01、UF-03；FR-03、FR-08、FR-12；AC-P0-09、10、12；AC-P1-05 |

#### 复盘信息区块顺序

1. 复盘范围和数据状态。
2. 本期目标与实际结果。
3. 成果/证据和能力变化。
4. 一个最大差距及依据。
5. 唯一调整、下一任务和续接点。
6. 保存/确认结果反馈。

复盘没有具体调整时，必须填写“不调整”的证据理由；纯总结不能完成复盘。

### IA-06 任务工作台（上下文页）

| 项目 | 定义 |
|---|---|
| 用户问题 | 当前任务进行到哪一步，现在应该做什么，怎样安全形成成果并证明完成？ |
| 进入条件 | 今日主行动；路线图当前任务；复盘允许的补强任务；节点详情中的相关计划任务 |
| 主要信息 | 返回来源；任务 ID/对象状态；上层目标链；为何现在做；时间盒；依赖/门禁；步骤；允许资源；受控材料状态；当前步骤内容；主要/支持成果；模板；完成规则；自检；证据；草稿/保存/提交状态；阻塞与续接 |
| 唯一主行动 | 随当前步骤变化：“开始闭卷首做”“完成当前步骤”“打开指定输入”“预览提交差异”“提交成果”“进入日复盘”；同一时刻只显示一个高强调动作 |
| 次要行动 | 保存草稿、查看上层目标、查看相关节点、查看允许资源、查看成果/证据、记录阻塞、返回来源 |
| 退出去向 | 正常返回来源；完成执行进入复盘；节点进入节点详情；成果/证据进入档案；阻塞后回今日或复盘 |
| 返回上下文 | 显示“返回今日/路线图/知识节点/复盘”；恢复来源筛选与位置；未保存时先进入保护路径 |
| 覆盖 | PS-03；UF-01、UF-02、UF-03；FR-02—07、FR-14；AC-P0-03—09、11、12；DT-01—05 |

#### 任务工作台固定区块

1. **上下文头部**：返回来源、任务 ID、对象状态、时间盒、数据状态。
2. **目标与门禁**：目标链、主要结果、依赖、门禁、为何现在做。
3. **执行步骤**：定位 → 闭卷首做 → 指定输入 → 主动加工 → 写入成果 → 自检 → 单点修订 → 收尾。
4. **当前步骤工作区**：只展开当前步骤的说明、输入和主行动。
5. **成果区**：目标路径、模板、草稿、最后保存时间、首次版/修订版。
6. **完成与证据区**：标准、当前证据、差距、判断状态。
7. **恢复与辅助区**：阻塞、错误、只读、复制草稿、返回来源。

#### 动态主行动规则

| 当前阶段 | 唯一主行动 | 完成后 |
|---|---|---|
| 定位未确认 | 确认本次最小结果 | 进入闭卷或指定输入 |
| 闭卷未开始 | 开始闭卷首做 | 进入独立草稿 |
| 独立版本未完成 | 保存首次版本 | 锁定首版并检查开放条件 |
| 指定输入可读 | 完成指定输入 | 进入主动加工 |
| 主动加工 | 完成当前练习 | 进入成果区 |
| 成果未提交 | 预览提交差异 | 进入确认状态 |
| 差异已确认 | 提交成果 | 进入自检 |
| 自检未完成 | 提交自检结论 | 通过、单点修订或阻塞 |
| 单点修订 | 保存本次修订 | 重新自检一次 |
| 会话可收尾 | 进入日复盘 | 打开复盘日收尾模式 |

“保存草稿”始终是次要动作，不与主步骤竞争。

### IA-07 知识节点详情（上下文页）

| 项目 | 定义 |
|---|---|
| 用户问题 | 这个节点是什么、何时使用或不用、怎样证明，以及它服务哪个计划任务？ |
| 进入条件 | 知识地图选中节点；任务工作台相关节点；复盘证据缺口；档案关联节点 |

### 6.2 受控材料异常分支

- **开放条件不满足**：材料保持锁定；主行动回到未完成的首次版本步骤。
- **直接地址/搜索命中**：只显示“受控材料未开放”和条件，不显示标题之外可能泄露答案的信息；返回任务工作台。
- **索引过期**：禁止正式开放材料；可继续独立草稿，提示刷新后再检查条件。
- **只读模式**：允许完成临时独立草稿并复制，不允许提交首版或开放材料。
- **开放后关系失效**：停止显示正文，保留首版和草稿，提示重新验证开放条件。
- **误开放证据**：标记为 Blocker，不继续任务完成流程；保留审计信息并回安全状态。

- **已有证据足够**：允许选择“不新增任务”，但必须记录证据和不调整理由。

## 8. 跨页面状态与恢复路径

### 8.1 状态决策表

| 状态 | 页面表现 | 允许动作 | 禁止动作 | 恢复路径 |
|---|---|---|---|---|
| 加载 | 保留页面骨架和主区位置；不显示 0 或空结果 | 取消等待、查看缓存状态（若存在） | 把加载当空状态 | 成功后原位呈现；失败转错误 |
| 空 | 说明为空的原因和对象范围 | 执行一个合法下一动作 | 创建虚假默认对象 | 今日→路线图；档案→清除筛选；复盘→返回当前任务 |
| 部分数据 | 保留可用信息，持续显示缺失关系和影响 | 阅读可用内容、查看问题详情、返回安全页面 | 补造父级、状态、证据或能力等级 | 刷新数据或回权威文件处理；恢复后保持上下文 |
| 过期 | 显示生成时间、权威来源和可能影响 | 继续阅读、保存临时草稿、刷新 | 正式提交、开放受控材料、静默覆盖 | 刷新成功后重验关系；失败转只读/错误 |

| 只读 | 持续标明原因和权威文件未改变 | 浏览、筛选、保存临时草稿、复制 | 正式提交、改状态、开放受控内容 | 权限/连接恢复后重验版本再提交 |
| 阻塞 | 显示对象、卡点、已有成果、解除条件、降级路径 | 记录阻塞、保存成果、执行安全降级动作、复盘 | 计入完成、自动跳过依赖 | 解除后回原任务步骤；未解除回今日/复盘 |
| 未保存 | 持久显示未保存标记、最后保存时间和目标 | 保存草稿、复制、留在页面、明确放弃 | 无提示离开或自动当正式成果 | 保存后继续导航；返回时恢复草稿与步骤 |

### 8.2 未保存内容路径

用户从任务工作台或复盘编辑区尝试离开时：

```text
检测到未保存内容
→ 显示结果明确的保护层
   ├─ 保存草稿并离开
   ├─ 留在当前页面
   └─ 放弃未保存修改（需要说明影响）
```

规则：

- “保存草稿并离开”只保存临时状态，不改变任务、成果或能力状态。
- 正式提交进行中时禁止重复提交；离开必须等结果或明确中止。
- 写回失败后“放弃”不能删除仍可恢复的本地草稿，除非用户再次明确确认。
- 浏览器前进/后退、全局导航和上下文返回使用同一保护逻辑。

### 8.3 错误范围

- **页面读取错误**：只影响当前页面；保留全局导航和来源信息。
- **关系解析错误**：显示缺失关系；不影响无关内容浏览。
- **提交错误**：保持编辑内容和提交前权威版本；任务状态不变。
- **全局索引错误**：进入只读故障页，提供权威 Markdown 使用说明；不显示伪造进度。
