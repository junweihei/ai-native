# AI Native Learning OS：数据与使用说明

## 产品定位

`AI_Native_Learning_OS_V2.html` 是个人 AI Native 学习工作台，不是新的成果存储库。

它负责：

- 通过知识树和架构地图提供方向导航；
- 将学习资源、每日记录、成果和验收证据关联到知识节点；
- 提供统一的节点四问学习卡；
- 展示学习状态、成果库和认知演变时间线。

## 数据原则

正式学习成果以工程内 Markdown 文件为唯一可信来源：

| 目录 | 数据角色 |
| --- | --- |
| `01-map/` | 知识地图和节点学习卡 |
| `daily-task/` | 每日学习记录 |
| `02-cases/` | 案例拆解 |
| `03-practice/` | 首测、错因、练习和复测 |
| `04-use/` | 真实任务及迭代版本 |
| `05-evidence/` | 闭卷讲解、迁移、验收和复盘 |

浏览器本地存储只保存：

- 节点学习状态；
- 尚未正式归档的临时草稿；
- 当前学习日和今日任务；
- 界面偏好。

## 推荐使用方式

1. 打开 `AI_Native_Learning_OS_V2.html`。
2. 点击“连接学习工程”。
3. 选择 `F:\GPT\ai-native` 项目根目录。
4. 在左侧知识树选择当天节点。
5. 先闭卷填写，再学习指定资料并校正。
6. 临时过程中使用“保存临时草稿”。
7. 完成后使用“写入学习工程”，正式文件进入 `01-map/`。
8. 如果浏览器不支持直接写入，使用“导出 Markdown”后保存到工程。
9. 将每日总体学习过程继续记录到 `daily-task/`。

## 节点学习卡固定结构

每个节点必须回答：

1. 它是什么？
2. 解决什么问题？
3. 什么时候使用或不使用？
4. 怎样证明它有效？

并保留：

- 学习前理解；
- 资料来源；
- AI 教练反馈与校正；
- 当前问号和下一步。

## 当前实现边界

- Markdown 关联主要依据文件名、标题和正文关键词自动推断，后续可以增加显式节点元数据。
- 文件夹连接权限由浏览器控制，每次重新打开页面可能需要重新授权。
- 正式成果不依赖浏览器本地存储，避免清理浏览器数据后丢失学习证据。
- 当前是本地单人学习工具，不引入数据库、账号系统或生产依赖。
